# 作品原址更新与空间管理员

## 已确认需求

- 个人作品、空间作品均允许重新上传文件，保留作品 ID、分享网址、访问数、标题、标签、原上传者、创建时间、可见状态、有效期与空间归属。
- 只有原上传者、空间创建者、该空间被授予权限的管理员可以更新。平台管理员也可以更新文件，作为上述限制的例外；其他平台角色身份本身不新增更新文件的特权。
- 各界面卡片的圆形悬停菜单增加“更新上传”，沿用当前弧形布局；管理表格也提供相同入口。
- 贡献者由空间作品的上传记录汇总，不能手动添加或移除成员。匿名上传只显示匿名贡献数量，不能授予账号权限。
- 空间右侧提供可展开、可关闭的贡献者浮层；个人空间管理页及平台管理页也能查看。
- 只有创建者可以授予、撤销贡献者的空间管理员权限；空间管理员和其他平台管理员都不能转授此权限。
- 空间管理员和创建者可以将空间作品退回上一个文件版本，也可以续期空间。

## 实现选择（2026-10-27 已获用户确认）

### 更新上传

选择单个 HTML 文件或作品文件夹后，在确认窗口明确告知“替换文件，保留网址和统计”。这是整份作品替换，不是将新文件叠加到旧目录。新文件全部验证、写入独立目录后，才切换作品的 rootPath；数据库只修改文件目录，不覆盖其他字段，访问数并发增长不受影响。失败保留旧文件；并发更新或更新期间删除作品时，拒绝过期提交并清理新文件。上传者和空间管理权限在接收文件前、提交前均检查。

上传支持沿用现有的单 HTML / 文件夹格式与入口校验，拒绝路径穿越和缺失 index.html 的文件夹。更新成功后刷新卡片预览，作品资源请求重新验证缓存，以免同名资源继续显示旧版本。

空间作品保留当前版本和紧邻的上一版文件。存在上一版时，空间管理员和创建者可通过卡片悬停菜单、管理表格中的“退回上一版”操作回退；普通上传者不能仅凭上传者身份回退。首次上传、尚未成功更新的作品不显示可用回退操作。回退仅切换文件内容，原网址、访问数、标题、标签、上传者、创建时间、可见状态、有效期和空间归属均不变。

回退沿用更新上传的权限重检、并发保护和缓存刷新规则。回退成功后将刚替换下来的版本保存为上一版，允许恢复；再次上传成功后只保留新的当前版与其上一版，更早文件在成功提交后清理。本轮不提供多级版本历史或个人作品的回退入口。作品删除、到期清理或空间永久删除时，同时清理保留的上一版文件。

### 空间权限

创建者仍由 Space.ownerUserId 唯一决定。新增 SpaceAdministrator 关联表保存授权，不改变 User.role，不影响其他空间。创建者可以在贡献者列表中为已注册贡献者授权、撤销授权；不能把创建者自己降为普通管理员。

| 操作 | 上传者 | 空间管理员 | 创建者 |
| --- | --- | --- | --- |
| 更新、重命名、显隐、删除作品 | 自己的作品 | 当前空间所有作品 | 当前空间所有作品 |
| 空间作品退回上一版 | 不可以，除非同时为管理员 | 可以 | 可以 |
| 管理标签、设置作品标签、批量管理、下载开关 | 无额外权限 | 可以 | 可以 |
| 进入空间管理、批量上传 | 无额外权限 | 可以 | 可以 |
| 授予／撤销管理员 | 不可以 | 不可以 | 可以 |
| 续期空间 | 不可以 | 可以 | 可以 |
| 删除、合并空间 | 不可以 | 不可以 | 可以 |

平台后台已有的运维权限保留，新增的管理员授权接口仍只允许空间创建者调用。管理员可在个人控制台“空间管理”看到被授权空间；普通贡献者继续从公开入口访问和上传。

贡献者按空间中现存且未删除作品的上传者汇总，显示用户名、作品数量及角色标识；其全部作品删除后不再出现在普通贡献者列表。不会额外建立永久贡献历史表。创建者与已有授权的管理员另以角色展示，管理员后来删除自己的全部作品时不会因此意外失去授权。名单不显示手机号、邮箱、IP 或浏览器信息；未登录访问公开空间也能看到公开贡献者信息。

### 原有功能衔接

现有空间合并只允许创建者或原有平台运维权限执行；同一创建者合并空间时保留被合并空间已有管理员授权，避免静默丢失协作权限；合并搬移作品时保留上一版引用，复制作品时独立复制上一版文件，不能共享会被另一份作品删除的目录。空间到期暂停作品更新、版本回退和协作管理，但保留授权记录；只有空间或用户真正删除时才通过外键级联清理。空间管理员续期使用与创建者相同的有效期校验及续期规则，不因此获得删除、合并或转授权限。删除及过期作品不能通过更新上传或回退恢复、延长有效期。

## 数据与上线

新增 SpaceAdministrator(spaceId, userId, createdAt)，以 (spaceId,userId) 为复合主键，外键关联 Space / User；Deployment 新增可空的 previousRootPath 字段记录上一版目录，已有作品默认为空。此次迁移仅新增授权表、索引及可空字段；不重写现有用户、作品、空间、访问数或文件。已有空间无需回填创建者授权；贡献者直接从现有上传记录汇总。

本地实现、迁移文件、测试和审查完成后，生产迁移须按项目 AGENTS.md 取得此次明确批准；此前账号体系迁移批准不视为本次批准。上线前备份数据库、上传文件与当前版本，保留生产 .env、storage 和依赖；不购买服务或升级依赖。

## 验收重点

- 新内容可通过原网址访问；更新前后原字段保持一致，正常访问仍累加原计数。
- 个人上传、空间公开卡片、空间管理、平台管理入口遵守相同授权规则。
- 非上传者／非空间管理员不能更新；权限撤销后再次提交立即被拒绝。
- 空间管理员可续期、退回上一版；普通上传者不能回退。回退后网址、统计和其他元信息保持原值，可恢复刚替换下来的版本；并发更新／回退不会覆盖较新提交。
- 新上传后只保留当前与上一版；删除、到期清理、空间合并正确处理两个版本，不删除其他作品引用的文件。
- 创建者可授权、撤销；受委托管理员不能管理授权或删除空间；更换空间 ID 不能越权。
- 无成员增删功能；现存作品贡献者与匿名贡献正确显示，名单不泄露联系方式；作品全部删除后普通贡献者消失，已有管理员授权仍保留。
- 错误文件、并发更新、数据库提交失败保留可用旧作品并清理临时文件。
- 后端 build、前端 typecheck/build、相称的权限与文件存储测试、浏览器交互检查。
