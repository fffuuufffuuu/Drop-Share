# Drop&Share 新首页与用户控制台设计

日期：2026-07-29

## 目标

为 Drop&Share 增加一个简洁的产品介绍首页，让首次访问者先理解网站用途，再通过醒目的“免费使用”按钮进入现有上传功能。

同时调整登录后的顶部导航，并完善普通用户控制台，使用户可以分别管理个人上传和空间。

## 页面与地址

- `/`：新的产品介绍首页。
- `/upload`：现有的个人上传页面。
- `/login`：现有登录和注册页面。
- `/dashboard`：登录用户控制台。
- `/admin`：现有管理员后台。

未知地址仍返回首页。

## 新首页

首页采用简洁的介绍页，不直接嵌入上传表单。

首屏包含：

- 主标题：“把网页变成一个随时可分享的链接”。
- 简短说明：支持上传单个 HTML 文件或完整网页文件夹，并生成访问链接。
- 主要按钮：“免费使用”，进入 `/upload`。
- 次要入口：“登录/注册”，进入 `/login`。

首页下方用简短内容介绍：

1. 上传单个 HTML 文件或完整文件夹。
2. 上传完成后立即获得可分享的网页链接。
3. 匿名上传默认保留 3 小时。
4. 注册登录后可以选择 1–24 小时的保留时间、查看个人上传记录并创建空间。

页面不会将登录用户的个人上传描述为永久保存，因为当前实际规则是最多 24 小时。

## 顶部导航

未登录时显示：

- 首页
- 免费使用
- 登录/注册

登录后显示：

- 首页
- 上传
- 当前用户名
- 管理后台（仅管理员可见）

用户名是进入控制台的链接，点击后前往 `/dashboard`。登录状态变化后，导航应立即刷新，不需要手动重新加载页面。

控制台内提供退出登录入口，退出后恢复未登录导航。

## 用户控制台

控制台包含两个相互独立的板块：

### 我的上传

只显示当前账号登录后直接上传的个人网页：

- 不包含匿名上传。
- 不包含上传到空间的网页。
- 不能查看其他账号的记录。

列表保留完整历史，显示网页名称、上传时间、到期时间和当前状态。

状态区分为：

- **正常**：尚未到期、尚未删除且可以访问。
- **已隐藏**：文件仍存在，但外部访问已关闭。
- **已过期**：已经超过到期时间。
- **已删除**：用户主动删除，文件已经清理。

状态判断优先级为“已删除、已过期、已隐藏、正常”，避免同一记录显示多个冲突状态。

正常记录提供访问入口。已隐藏、已过期和已删除记录继续显示历史信息，但不显示无效的访问入口。

### 空间管理

保留现有空间创建和空间列表功能。空间内上传的网页继续在对应空间中查看和管理，不在“我的上传”中重复出现。

## 服务端规则

新增当前用户的个人上传查询接口。

服务器必须根据登录令牌确认用户身份，并只查询：

- `ownerUserId` 等于当前用户；
- `spaceId` 为空的个人上传。

接口返回页面所需的公开信息和状态字段，不返回服务器文件路径、上传者网络信息或其他敏感字段。

查询包含已经过期或标记删除的历史记录。现有数据结构已包含到期时间和删除时间，预计不需要数据库迁移。

未登录请求返回未登录错误。用户不能通过修改请求参数读取其他账号的数据。

## 视觉方向

首页延续现有深色导航和蓝色强调色，但增加更清晰的主标题、留白和功能说明，使页面更像可信赖的产品入口。

“免费使用”是页面最醒目的操作。桌面端和手机端均应保持标题、说明和按钮清晰可见，不使用复杂动画或装饰。

控制台沿用现有管理界面的简洁卡片风格，通过板块切换和状态标签区分内容。

## 验证标准

前端验证：

- `/` 显示介绍内容和“免费使用”按钮。
- “免费使用”进入 `/upload`。
- 未登录时显示“登录/注册”。
- 登录后显示用户名，不再显示“登录/注册”。
- 点击用户名进入控制台。
- 管理员仍能看到管理后台入口。
- 控制台将“我的上传”和“空间管理”分开。
- 个人记录正确显示正常、隐藏、过期和删除状态。
- 无效记录不显示可访问链接。

服务端验证：

- 未登录用户不能查询个人上传历史。
- 登录用户只能查询自己的个人上传。
- 空间内网页不出现在个人上传列表。
- 已过期和已删除记录仍被返回。
- 返回结果不包含服务器路径等敏感字段。

最终运行全部服务端测试与构建，以及前端测试、类型检查和构建。

## 发布边界

本地开发完成后再单独安排生产发布。发布前必须备份数据库、上传文件和当前版本，并保留回退路径。

生产发布不得覆盖 `server/.env` 或 `server/storage`，不得提交环境变量、数据库、上传文件、备份或凭证。
