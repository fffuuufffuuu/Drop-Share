# Drop&Share 管理后台设计

日期：2026-07-29

## 目标

为 Drop&Share 增加仅管理员可访问的管理后台。管理员登录后可以查看全部尚未删除的网页，下载或永久删除单个网页，并按空间查看、下载或永久删除整个空间。

首位管理员账号为 `fffuuu`。

## 范围

管理后台地址为 `/admin`，使用现有登录系统，不新增独立的管理员密码。

后台包含两个板块：

1. **个人上传**
   - 包含所有不属于空间的网页。
   - 同时包含登录用户上传和未登录的匿名上传。
   - 匿名上传明确标记为“匿名”。

2. **空间**
   - 显示所有空间。
   - 点击空间后查看其中全部网页。
   - 支持下载或永久删除空间内的单个网页。
   - 支持将整个空间打包下载或永久删除。

本次不包含回收站、操作日志、批量选择删除和新增独立管理员登录页。

## 管理员身份

用户账号增加“普通用户 / 管理员”身份。`fffuuu` 在上线时被设为管理员。

管理员仍从现有登录页登录。登录成功后，前端根据服务器返回的账号身份显示“管理后台”入口。

管理权限必须由服务器在每次请求时重新验证。普通用户即使直接访问 `/admin` 或手工调用后台接口，也不能读取或修改管理数据。

## 页面结构

### 管理后台首页

页面顶部显示标题、当前管理员和退出入口，下方使用“个人上传”“空间”两个切换板块。

### 个人上传

每条网页记录显示：

- 网页名称
- 上传者用户名，或“匿名”
- 上传时间
- 到期时间
- 显示状态
- 网页访问链接
- 预览、下载 ZIP、永久删除操作

默认只显示尚未删除且服务器仍可管理的记录。已经过期并被清理的记录不显示。

### 空间

每个空间显示：

- 空间名称
- 空间标识
- 创建者
- 创建时间
- 网页数量
- 进入详情、下载 ZIP、永久删除操作

空间详情显示该空间内的全部尚未删除网页，并提供预览、下载 ZIP 和永久删除操作。

## 下载规则

单个网页下载为 `网页名称.zip`。压缩包由服务器按请求即时生成，不在服务器长期保存副本。

整个空间下载为 `空间名称.zip`，其中每个网页放在独立文件夹内。文件夹优先使用网页名称；如果出现重名，则自动追加编号，防止内容相互覆盖。

下载前检查源文件是否仍然存在。如果文件已被定时清理或意外缺失，返回清晰提示，不生成空压缩包。

## 删除规则

所有删除均为永久删除，不进入回收站。

删除单个网页前显示二次确认，明确说明文件无法恢复。服务器先删除网页文件，成功后再删除数据库记录；文件清理失败时保留记录并返回错误，方便再次处理。

删除整个空间前显示更强的确认提示：“空间及其中所有网页都会永久删除”。服务器逐一清理空间内网页文件，全部成功后再删除空间及相关记录。任一文件清理失败时，空间记录保留并报告失败，避免出现后台显示已删除但服务器仍残留文件的情况。

## 服务端结构

新增独立的管理员权限检查和管理员接口，避免把管理员逻辑混入普通用户接口。

管理员接口负责：

- 查询全部个人上传网页
- 查询全部空间及网页数量
- 查询指定空间及其网页
- 下载单个网页 ZIP
- 下载整个空间 ZIP
- 永久删除单个网页
- 永久删除整个空间

所有列表只返回页面实际需要的信息，不返回密码摘要、服务器绝对路径等敏感字段。

## 错误处理

- 未登录访问：要求登录。
- 普通用户访问：明确拒绝，不泄露管理数据。
- 记录不存在：提示目标不存在或已被删除。
- 文件不存在：提示源文件已不存在。
- 压缩失败：终止下载并记录服务器错误。
- 删除失败：保留可管理记录并提示重试。
- 重复操作：第二次删除返回目标不存在，不影响其他数据。

## 验证标准

服务端测试覆盖：

- 普通用户无法访问任何管理员接口
- 管理员可以访问
- 登录用户上传与匿名上传均正确归入“个人上传”
- 空间及其网页正确归类
- 单网页 ZIP 保留目录结构
- 整空间 ZIP 按网页分文件夹且重名不覆盖
- 单网页永久删除
- 整空间永久删除
- 文件删除失败时保留管理记录

前端测试或等价验证覆盖：

- 只有管理员看到管理后台入口
- `/admin` 包含“个人上传”和“空间”两个板块
- 空间可进入详情
- 下载操作指向正确目标
- 单网页和整空间删除均有明确二次确认
- 成功与失败结果均有清晰反馈

最终验证包括服务端测试与构建、前端类型检查与构建。

## 发布边界

本轮先在本地实现和验证，不直接修改生产服务器。

正式部署前必须：

1. 备份生产数据库和上传文件。
2. 确认数据库结构更新方案。
3. 将 `fffuuu` 设置为管理员。
4. 在维护窗口内更新后端和前端。
5. 验证普通用户权限、管理员登录、列表、下载和删除。
6. 保留可执行的回退方案。
