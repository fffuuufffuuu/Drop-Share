# 作品版本与空间协作发布准备

## 功能

作品可完整重新上传，原网址、访问数、标题、标签、上传者及有效期保持不变。空间作品保留当前版和上一版，空间创建者或被授权管理员可以回退；回退后还可恢复刚替换下来的文件。平台管理员按已确认方案可以更新文件；回退仍要求空间管理权限。

贡献者名单自动汇总空间内现存作品的上传者，匿名贡献合并计数；没有成员新增、移除接口。只有创建者可授予、撤销贡献者的管理员权限。空间管理员可以管理作品、标签、下载开关、批量上传和续期；不能转授、删除或合并空间。创建者及已有管理员没有作品时仍显示其角色。

## 迁移范围

SQL：`server/prisma/migrations/20261027000000_space_administrators_and_versions/migration.sql`。

- Deployment 新增可空 previousRootPath；现有作品为空，没有可回退版本，首次更新后开始保留上一版。
- 新建 SpaceAdministrator 关联表、复合主键和用户索引，关联已有 Space / User，删除时级联清理授权。
- 不删除、重写或回填现有作品、用户、空间及统计；不改变认证提供方、密码或全站角色。

用户于 2026-10-27 明确批准“上线”；此次生产迁移已执行成功。发布前 Prisma validate 与本机客户端生成通过；开发阶段没有 MySQL 测试实例，生产迁移的成功以实际迁移日志、业务记录校验和上线探针为证。

## 验证

后端 192 项、前端 115 项通过，规定构建与类型检查通过。包括权限撤销期间上传、CAS 冲突、失败暂存清理、真实文件两版切换、批量删除/到期清理两版、空间合并独立复制上一版和授权继承，以及续期后清理不得删除有效作品。独立审查发现的问题已修复并复核。

本机浏览器用虚构账号、内存数据库与真实上传/文件路由检查了确认窗口、文件上传、回退、原分享链接、累计统计、右侧贡献者浮层及创建者授权按钮。虚构授权点击在收到用户即时批准后执行。此验收不涉及线上账号或 CloudBase。

## 经批准后的上线顺序

1. 再检查磁盘空间、当前服务及数据状态，暂缓写入；备份数据库、上传文件和当前版本，并验证压缩包/校验和。当前剩余空间约 1.6 GB；存储备份只有在完整逐文件比对一致后才能复用旧不可变归档，否则将备份存到服务器外，不擅自删旧备份或购买扩容。
2. 使用现有版本 Prisma 执行 migrate deploy；为生产 Linux/OpenSSL 生成或准备对应客户端，不升级依赖。保存迁移日志及前后业务记录数量、归属和计数校验。
3. 窄范围发布后端编译文件、前端构建和对应源码；保留生产 server/.env 与 server/storage。
4. 验证健康、HTTPS、公开空间、认证、新权限和版本行为，再由用户在自己的空间验收授权与更新。不得在未获同意时改动真实作品或权限。

## 回退

迁移是增量，回退应用版本时保留新增表和可空列，不执行破坏性 down migration。回退前保存当时已发布的根路径和版本数据；如果已有新版本操作，不可直接恢复旧数据库而覆盖新作品信息。保留所有当前/上一版文件；已删除的更早版本不属于产品历史保留范围。必要时在停写状态下按对应一致备份恢复数据库、文件和应用。
