# 卡片聚焦、简介与评论

空间入口与“我的上传”共用聚焦网格。点击卡片展开为整行，预览在左、信息与操作在右；窄屏改为上下排列。展开卡片不显示扇形菜单；点击其他卡片切换，点击页面空白或按 Escape 收起。布局变化使用 420ms 动画，遵守系统减少动态效果设置。弹窗操作不会触发外部收起。

## 数据与权限

- `GET /api/deployments/:workId/discussion`：读取简介及最近 100 条评论（最新在前），返回 `canEdit`、`canComment`。
- `PATCH /api/deployments/:workId/description`：所有者、空间管理者或站点管理员编辑简介，最多 2000 字。
- `POST /api/deployments/:workId/comments`：仅注册并登录的用户可发表评论，正文须为 1–1000 字，作者取服务端认证身份。游客可读取评论，不显示评论输入框，直接提交返回 401。
- 已删除或到期的作品不可访问。隐藏作品仅管理者及所有者可读取和操作。
- 已有作品的简介默认为空；评论保存在 `DeploymentComment`，作品或作者被永久删除时级联删除对应评论。
